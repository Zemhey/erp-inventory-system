## 建议执行顺序（先做这条主线）

1. **P0-01 → P0-04**（运行时契约校验 + CI 门禁）——最便宜、覆盖最广；
2. **P0-11 → P0-12**（test 后门 + 生产不注册验证）——解锁跨月/效期等难造场景；
3. **P0-09 → P0-10 → P0-13**（test-kit 数据工厂 + 断言库）——让后续用例更省事；
4. **P0-05 → P0-08**（k6 三场景 + nightly）——把“逻辑对”升级为“扛得住”；
5. 再进 P1（前端缺口、跨端一致性）；
6. 最后 P2（安全门禁、flaky 治理、可选增强）。
