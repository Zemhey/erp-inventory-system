> `season_code`（如 `2026SS`）+ `band_code`（波段，可空）+ `launch_date`（上市日期）。

## 3. 这轮对标改变了什么（对 V2 蓝图的修正）

### 3.1 认下来的 4 项（已写入蓝图 v0.3）

| FR | 功能 | 核实强度 | 说明 |
|---|---|---|---|
| **FR-SAL-10** | 组合商品/套装拆解 | 🟢 两家官网原文（"组合套装" / "组合品"） | 新增 `product_bundles` / `bundle_items`，**INV-16 拆解守恒** |
| **FR-INV-13** | 补货建议（min/max） | 🟢 两家官网 + 管家婆"进货建议表" | **只加 2 列**，不建表；且可加"按销量预测"口径（P2） |
| **FR-SAL-11** | 发货选仓 / 分配策略 + 拆单 | 🟢 两家官网（"自动分配仓库物流" / "多策略分配库存"） | **只加 1 列** `warehouses.priority` |
| **FR-MDM-08** | 季节/波段维度 | 🟡 多来源一致的行业惯例 | **加列**：`season_code` + `band_code` + `launch_date` |

### 3.2 判定"并入"或"不加"的（附理由）

| 项 | 判定 | 理由（用蓝图的闸门解释） |
|---|---|---|
| 波次拣货 | **并入 FR-SAL-06** | 闸门 4（替代）：波次只是拣货单的批量视图，不需要新实体 |
| 售后工单协同 | **降为 P2** | 闸门 1：它不补任何链的断点（我们的退货单据已闭环）；但"多角色协同/绩效"有业务价值，有余力再做 |
| 多平台订单同步 | **不加** | 闸门 1+2：无真实平台 API；只能造假数据，且不产生新不变量 |
| 分销/供销 | **不加** | 闸门 1：不是任何一条链的断点；且需要真实供销双方 |
| 复式记账/凭证 | **不加** | 闸门 2：会计恒等式与"进销存不变量"是两套命题，混进来会稀释测试重心 |
| 多币种 | **不加** | 闸门 3：会让金额断言组合翻倍，无新洞察 |
| 商品刊登/一键铺货 | **不加** | 无真实电商平台可对接 |

### 3.3 一处需要修正原判断的地方

**原判断**（蓝图 v0.2）：`FR-INV-13 补货建议` 用固定 min/max 阈值即可。

**核实后修正**：万里牛原文是"**动态销量预测采购量**"，管家婆是"库存下限 + 进货建议表"。
→ **主流做法有两档**：
- **档 1（min/max 阈值）**：简单、确定性强、**最适合表驱动测试** → **V2 必做**；
- **档 2（销量预测）**：需要历史销量窗口 + 预测算法，测试变成"预测口径是否正确" → **降为 P2**，且**不能进 CI 门禁**（预测结果不稳定会 flaky）。

> 这正好是一个"用闸门筛掉复杂度"的实例：**两个都做会拖长工期，档 1 已经能闭环采购链**。

## 4. 一句话总结这轮对标的价值

> **对标 5 家厂商，找到 10 个差异点，最终只加 4 项功能。**
>
> 如果按"别人有就抄"，这里会变成加 10 个功能、5 张表、3 个新模块，
> 而其中 6 项（多平台同步、分销、复式记账、多币种、商品刊登、波次独立建模）**要么需要不存在的外部系统，要么属于另一个专业领域，要么只是已有能力的视图**。
>
> **四条闸门的作用就在此：它让"对标"变成"筛选"，而不是"抄作业"。**

## 6. 复现方法（我实际用的命令）

```bash
# 1) 探测哪些域可达（沙箱只放行部分出站）
for h in www.hupun.com www.wangdian.cn www.yonyou.com www.jushuitan.com; do
  curl -s -o /dev/null -L --max-time 10 -A "Mozilla/5.0" -w "$h %{http_code} %{size_download}\n" "https://$h"
done

# 2) 抓取官网首页/产品页（注意 -L 跟随跳转、带 UA 与 Accept-Language）
curl -s -L --max-time 25 -A "Mozilla/5.0 (Windows NT 10.0; Win64; x64) Chrome/120.0" \
  -H "Accept-Language: zh-CN,zh;q=0.9" https://www.hupun.com/product/erp -o hn_erp.html

# 3) 抽正文（去 script/style/标签）
#    注意：本机 PowerShell 处理中文时正则里的中文引号易触发解析错误，建议用文件方式

# 4) 中文检索（搜狗/神马；高频请求会触发验证码，需节流）
curl -s -L --max-time 25 -A "Mozilla/5.0 ... Chrome/120.0 Mobile Safari/537.36" \
  -H "Accept-Language: zh-CN,zh;q=0.9" "https://m.sm.cn/s?q=<urlencoded>" -o sm.html
```
