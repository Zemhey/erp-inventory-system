# V3 · 商业化完整度扩展计划书

> 目标：把当前"能跑通的进销存"补成"看起来、点起来都像大型商业 ERP"的系统。
> 定位：**课程作业**。首要矛盾是**功能覆盖广度**，不是工程质量。
> 日期：2026-10-25 · 基线：main `a0cf1ba`（B1+B2 已合并，V18）

---

## 0. 结论先行

**当前系统不是"功能弱"，是"露出来的少"。**

后端已经 36 个控制器、175 个接口、59 张表，覆盖采购/销售/库存/退货/结算/成本/报表/审批/租户 —— 业务底盘接近中型 ERP。但前端只有 **23 个业务页面 + 31 条平铺菜单**，打开就像一个小工具。

**所以本轮的主攻方向是"把已有的能力摆出来 + 补财务和系统中心"，不是重做业务逻辑。**

| 判断 | 内容 |
|---|---|
| **做什么** | ① 菜单分 8 组 ② 工作台重做 ③ 财务中心 ④ 系统设置中心 ⑤ 已有控制器的页面补齐 ⑥ 报表中心 |
| **不做什么** | 生产制造(MRP/BOM/车间)、HR 人事薪酬、CRM 商机、电商对接、多币种、复式记账全套 |
| **量化目标** | 页面 23 → **约 52**；菜单 31 平铺 → **8 组 ~60 项**；后端模块 12 → **15**（+fin / +org / +prm） |
| **测试口径** | 4 道轻门禁，**不写 E2E、不跑 1218 条后端用例**（见 §6） |

## 2. 对标依据：市面系统"大"在哪里

### 2.1 调研来源

### 2.2 归纳：商业系统的"完整感"来自 5 个东西

1. **菜单要分级** —— 大厂没有一个是一层平铺的。金蝶是 6 朵云，每朵云下 10~20 项。
2. **工作台是门面** —— 一登录就要看到 KPI、图表、待办、预警。这是"第一眼"。
3. **财务必须独立成中心** —— 所有 ERP 的第一大模块都是财务（金蝶财务云、SAP 的 FI/CO）。进销存没有财务，永远像"库存小工具"。
4. **单据要有"中心"概念** —— 不是散落的列表，而是"待审 / 待办 / 我发起的 / 全部"。
5. **系统设置要厚** —— 组织架构、参数、单号规则、打印模板、导入导出、日志。这些页面技术上最简单，但最撑"企业级"观感。

## 4. 技术方案

### 4.1 后端

沿用现有三段式，不引入新框架：

```
com.erp.<module>/
  api/        XxxController      （@RestController，/api/v1/xxx）
  application/XxxService         （事务边界在这里）
  repository/ XxxRepository      （Spring Data JPA）
  domain/     Xxx 实体
```

- **迁移**：从 `V19__v3_finance.sql` 起顺序编号，一个批次一个文件；新表**必须**带 `tenant_id`（否则租户隔离门禁会漏）。
- **权限码**：新增 `fin:read` / `fin:write` / `org:read` / `org:write` / `prm:read` 等，写进角色初始化。
- **契约**：新端点同步写 `packages/api-contract/openapi.yaml`，操作数会从 175 涨到约 260。
- **复用**：单据状态机、幂等 requestId、审计留痕、租户上下文 —— 全部走现有基础设施，不另起一套。

### 4.2 前端

- **菜单**：`MainLayout` **已经支持** `el-sub-menu` 分组（`group.flat` 开关）。只需把路由 `meta` 加上 `group` 字段 + 在布局里维护 8 个 group，**不需要重构布局**。
- **页面**：统一用 `PageTable` 骨架（查询区 / 工具栏 / 表格 / 分页 / 抽屉表单），新页面复制 `DictView` 或 `SupplierView` 改。
- **图表**：现在没有图表库。建议引入 `echarts` + `vue-echarts`（体积可接受，按需引入），工作台和大屏用它。
- **权限**：路由 `meta.permission` 已有守卫，新页面照写即可。

### 4.3 数据

- 新增约 **22 张表**（财务 8 / 系统 8 / PRM 2 / 其他 4），总表数 59 → 约 81。
- 演示数据：写一个 `seed-v3.sql`（或 Flyway `afterMigrate` 回调），保证一登录每页都有数据 —— **空页面比没页面更伤观感**。
