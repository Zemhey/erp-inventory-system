# ADR 索引（架构决策记录）

> **ADR = Architecture Decision Record**：把"为什么这么选"写下来。
> 作用：三个月后你忘了理由时能查；答辩时能答"为什么不用 X"；面试时证明你有工程判断。

## 何时写 ADR

- 选了某技术/方案，而**存在合理替代**时
- 明确**划掉**某个方案时（如"不做微服务"）
- 决定影响多个模块或长期维护时

## 状态

`提议` → `已采纳` → `已废弃` / `被 ADRx 取代`

## 模板

```markdown
# ADR-xxxx: 标题
- 状态：已采纳
- 日期：YYYY-MM-DD
- 背景：我们面临什么问题？
- 决策：我们决定做什么？
- 理由：为什么？考虑过哪些替代方案？
- 后果：正面影响与要接受的代价
```
