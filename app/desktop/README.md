## 开工时的硬约束（先写下来，免得将来又长出第二套业务）

1. **不重写业务界面。** Electron 只加载 `frontend/web` 的构建产物
   （`main` 进程里 `loadFile('…/dist/index.html')`），渲染进程复用 Web 端全部页面。
   判断标准很简单：**如果一段代码在描述"某个业务页面长什么样"，它就该在 `frontend/web`，不该在这里。**
2. **只做只有桌面能做的事**，否则这个端没有存在价值：
   - 离线：本地缓存 + 断网可查（配合 `infra/standalone` 的单机版口径）
   - 本地硬件：打印（单据套打到针式打印机）、串口/电子秤一类
   - 系统集成：托盘常驻、开机自启、深链、多窗口
3. **API 层不另写一份。** 继续走 `packages/api-contract`，端点变化由主库驱动。
4. 打包产物目录固定在本目录的 `dist/`，不入库。

## 前置依赖

- 单机版（10%）先真机验通 —— PC 端的离线能力和它共用同一套本地后端形态。
- 必做四项（服务端 / Web / 小程序 / 安卓）先交付。
