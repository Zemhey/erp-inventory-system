## 1. 申请新增的路径

### 1.1 `POST /api/v1/cost/recalculate`

- 权限：`cst:recalc`
- 幂等头：`X-Request-Id` 必填
- 请求体：无
- 响应 `data`：

```json
{
  "layerCount": 12,
  "inboundCostAmount": 120000,
  "outboundCostAmount": 45000,
  "endingCostAmount": 75000,
  "balanced": true
}
```

- 说明：从 `inventory_ledger` 全量回放重建 `cost_layers`；`balanced` 表示
  `inboundCostAmount == outboundCostAmount + endingCostAmount`（INV-11）。

### 1.2 `POST /api/v1/cost/monthly`

- 权限：`cst:monthly`
- 幂等头：`X-Request-Id` 必填
- 请求体：

```json
{ "period": "2026-10" }
```

- 响应 `data`：

```json
{
  "period": "2026-10",
  "duplicate": false,
  "items": [
    {
      "skuId": 1,
      "warehouseId": 2,
      "openingQty": 0,
      "openingCostAmount": 0,
      "inboundQty": 10,
      "inboundCostAmount": 10000,
      "outboundQty": 4,
      "outboundCostAmount": 4000,
      "closingQty": 6,
      "closingCostAmount": 6000
    }
  ],
  "marginRecordCount": 1
}
```

- 错误：账期已锁 → 409 `SET_PERIOD_CLOSED`；`period` 非法 → 400 `SYS_VALIDATION_ERROR`。
- 说明：同账期无数据变化时重复执行 `duplicate=true`，业务字段与 `computedAt` 不变。

### 1.3 `GET /api/v1/cost/monthly?period=2026-10`

- 权限：`cst:read`
- 响应 `data`：`{ "items": [ ...同 1.2 的 items... ] }`
- `period` 非法 → 400 `SYS_VALIDATION_ERROR`。

### 1.4 `GET /api/v1/reports/profit?from=2026-10&to=2026-12&groupBy=product`

- 权限：`rpt:read`
- 参数：
  - `from` / `to`：`yyyy-MM`，闭区间，`from > to` → 400；
  - `groupBy`：`product`（默认）| `customer` | `period`。
- 响应 `data`：

```json
{
  "items": [
    {
      "key": "1",
      "label": "白色 T 恤 · 白-L",
      "qty": 4,
      "revenueAmount": 4000,
      "costAmount": 1600,
      "grossProfitAmount": 2400,
      "grossMarginRateBp": 6000,
      "orderCount": 1
    }
  ]
}
```

- 金额单位：分；`grossMarginRateBp` 为万分比（6000 = 60%）。
- 说明：数据来自成本月结生成的 `margin_records`；未做成本月结的期间返回空 items，
  前端在页面上提示「请先执行成本月结」。
- 备注：该路径与 `docs/00` 已规划的 `FR-RPT-04 GET /reports/profit` 一致。

## 3. 权限码申请

| 权限码 | 授予角色 | 用途 |
|---|---|---|
| `cst:read` | ADMIN / FINANCE / VIEWER | 查询成本月结 |
| `cst:recalc` | ADMIN / FINANCE | 重算成本层 |
| `cst:monthly` | ADMIN / FINANCE | 执行成本月结 |

权限种子写入 V12 迁移，不改 V3/V5 的既有行。

## 4. 响应与错误约定

- 统一包络 `{code:"OK", message:"success", data}`；
- 金额一律整数分；毛利率为万分比；
- 写接口缺 `X-Request-Id` → 400（沿用全局异常处理）；
- 权限不足 → 403 `IAM_FORBIDDEN`；账期锁 → 409 `SET_PERIOD_CLOSED`；
- 参数非法 → 400 `SYS_VALIDATION_ERROR`，message 含字段名与合法取值。
