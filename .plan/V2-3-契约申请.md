# V2-3 契约申请（FR-SAL-05 ~ 11 / FR-MDM-08）

> 申请人：V2-3 销售闭环泳道（feat/v23-sal-loop）
> 依据：`.plan/V2-3-计划书.md`
> 本文件**不是**契约本体。本泳道不是 `packages/api-contract/openapi.yaml` 的 owner，
> 不修改契约；合并时由清场把下列端点落进契约，并删除
> `ApiContractMappingIT.UNDOCUMENTED_DEBT` 中对应的"V2-3"条目。
> 所有路径前缀 `/api/v1`；所有写操作必须携带 `X-Request-Id`（缺失 → 400 `SYS_VALIDATION_ERROR`）；
> 金额均为整数分；日期为 `yyyy-MM-dd`；分页沿用 `page/size`。

## 1. 报价单

### 1.1 GET `/sales-quotes`
- 权限：`sal:read`
- Query：`status`（DocumentStatus）、`customerId`、`page`、`size`
- 200：`ApiPageResponse<SalesQuote>`

### 1.2 GET `/sales-quotes/{id}`
- 权限：`sal:read`
- 200：`ApiResponse<SalesQuote>`
- 404：`SAL_QUOTE_NOT_FOUND`

### 1.3 POST `/sales-quotes`
- 权限：`sal:quote`
- 请求头：`X-Request-Id`
- Body：
```json
{
  "customerId": 1,
  "bizDate": "2026-10-23",
  "validUntil": "2026-11-23",
  "remark": "双十一报价",
  "lines": [
    { "skuId": 1, "qty": 10, "unitPriceAmount": 12900, "discountRate": 9500 }
  ]
}
```
- 201：`ApiResponse<SalesQuote>`
- 400：`SYS_VALIDATION_ERROR`（明细为空/数量非正/折扣越界/有效期早于业务日期）
- 404：`SYS_NOT_FOUND`（客户不存在）
- 409：`SYS_DUPLICATE_REQUEST`（幂等键复用到另一张报价单）

### 1.4 POST `/sales-quotes/{id}/submit|approve|reject|void`
- 权限：`sal:quote`
- 200：`ApiResponse<SalesQuote>`
- 404：`SAL_QUOTE_NOT_FOUND`
- 409：`SAL_QUOTE_STATUS_ILLEGAL`（非法状态转移）

### 1.5 POST `/sales-quotes/{id}/convert`
- 权限：`sal:quote`（Controller 的 `@RequirePermission` 为单码；SALESPERSON 同时具备 `sal:create`）
- Body：
```json
{ "warehouseId": 1, "remark": "转化备注" }
```
`warehouseId` 可省略：省略时按 `warehouses.priority` 自动选仓/拆单（同 2.1）。
- 200：`ApiResponse<SalesOrder>`（首次转化与同键重放都返回该订单）
- 404：`SAL_QUOTE_NOT_FOUND`
- 409：`SAL_QUOTE_STATUS_ILLEGAL`（非 APPROVED / 已过期 / 已转化后用新幂等键）
- 409：`SAL_CREDIT_LIMIT_EXCEEDED`（信用不足；报价单保持 APPROVED，无预占）
- 409：`INV_INSUFFICIENT_STOCK`（库存不足；整单回滚，无预占）

## 2. 出货单扩展

### 2.1 POST `/sales-orders/auto-split`
- 权限：`sal:create`
- 请求头：`X-Request-Id`
- Body：
```json
{
  "customerId": 1,
  "bizDate": "2026-10-23",
  "remark": "自动选仓",
  "lines": [
    { "skuId": 1, "qty": 15, "unitPriceAmount": 12900, "discountRate": 10000 },
    { "bundleId": 3, "qty": 2, "unitPriceAmount": 0 }
  ]
}
```
每行二选一：`skuId` 或 `bundleId`。
- 201：`ApiResponse<SalesOrder>`；`lines[].allocations` 返回 `[{warehouseId, qty, reservations:[...]}]`
- 400：`SYS_VALIDATION_ERROR`
- 409：
  - `INV_INSUFFICIENT_STOCK`：所有仓合计仍不足；无任何预占
  - `SAL_CREDIT_LIMIT_EXCEEDED`：信用超额；无任何预占
  - `MDM_BUNDLE_NOT_FOUND` / `MDM_BUNDLE_DISABLED`
- 说明：单仓足够时只产生一个 `warehouseId` 的分配；不足才跨仓拆分配。

### 2.2 POST `/sales-orders/{id}/shipments`
- 权限：`sal:pick`
- 请求头：`X-Request-Id`
- 200：`ApiResponse<ShipmentPlanResult>`：
```json
{
  "planId": 9,
  "salesOrderId": 100,
  "shipments": [
    {
      "id": 1, "shipmentNo": "SP20261023-0001", "warehouseId": 2,
      "status": "DRAFT",
      "lines": [
        { "id": 11, "shipmentLineId": 11, "salesOrderLineId": 5, "skuId": 1,
          "batchNo": "B1", "plannedQty": 10, "pickedQty": 0 }
      ]
    }
  ]
}
```
- 409：`SAL_STATUS_ILLEGAL`（订单非 APPROVED/PARTIAL、无 ACTIVE 预占）
- 幂等：同键重放返回首次计划。

## 3. 发货作业

### 3.1 GET `/shipments`
- 权限：`sal:read`
- Query：`status`（DRAFT/PICKING/PICKED/COMPLETED）、`salesOrderId`、`page`、`size`
- 200：`ApiPageResponse<Shipment>`

### 3.2 GET `/shipments/{id}`
- 权限：`sal:read`
- 200：`ApiResponse<Shipment>`
- 404：`SAL_SHIPMENT_NOT_FOUND`

### 3.3 POST `/shipments/{id}/scan`
- 权限：`sal:pick`
- Body：
```json
{ "shipmentLineId": 11, "qty": 4, "barcode": "6901000001" }
```
`barcode` 可选；提供时必须与该行 SKU 的条码一致。
- 200：`ApiResponse<Shipment>`（返回累计 `pickedQty` 与状态）
- 400：`SYS_VALIDATION_ERROR`（数量非正/条码不匹配）
- 404：`SAL_SHIPMENT_NOT_FOUND`
- 409：`SAL_SHIPMENT_STATUS_ILLEGAL`（已确认/已作废）
- 409：`SAL_SHIPMENT_OVER_PICK`（扫码累计超过计划数量）

### 3.4 POST `/shipments/{id}/confirm`
- 权限：`sal:ship`
- 请求头：`X-Request-Id`
- 200：`ApiResponse<Shipment>`
- 409：`SAL_SHIPMENT_STATUS_ILLEGAL`（未全部扫码 / 非 PICKED）
- 409：`INV_INSUFFICIENT_STOCK`（预占已失效，事务回滚）
- 幂等：同键重放返回首次结果；新键重复确认 → 409。

## 4. 套装

### 4.1 GET `/product-bundles`
- 权限：`sal:read`
- Query：`keyword`、`onlyEnabled`、`page`、`size`
- 200：`ApiPageResponse<ProductBundle>`

### 4.2 GET `/product-bundles/{id}`
- 权限：`sal:read`
- 200：`ApiResponse<ProductBundle>`
- 404：`MDM_BUNDLE_NOT_FOUND`

### 4.3 POST `/product-bundles`
- 权限：`sal:bundle`
- Body：
```json
{
  "code": "BUNDLE-DENIM-01",
  "name": "牛仔三件套",
  "priceAmount": 39900,
  "enabled": true,
  "items": [
    { "componentSkuId": 1, "ratioQty": 2 },
    { "componentSkuId": 2, "ratioQty": 3 }
  ]
}
```
- 201：`ApiResponse<ProductBundle>`
- 409：`MDM_BUNDLE_DUPLICATED`
- 400：`SYS_VALIDATION_ERROR`（items 为空/ratio<=0/组件 SKU 重复）

### 4.4 PUT `/product-bundles/{id}`
- 权限：`sal:bundle`
- Body 同 4.3（不含 code）
- 200：`ApiResponse<ProductBundle>`
- 404：`MDM_BUNDLE_NOT_FOUND`

### 4.5 POST `/product-bundles/{id}/disable`
- 权限：`sal:bundle`
- 200：`ApiResponse<ProductBundle>`

### 4.6 GET `/product-bundles/{id}/availability`
- 权限：`sal:read`
- Query：`warehouseId`（可省略；省略返回汇总）
- 200：
```json
{
  "bundleId": 3,
  "warehouseId": 1,
  "availableQty": 5,
  "components": [
    { "componentSkuId": 1, "ratioQty": 2, "availableQty": 10, "maxBundles": 5 },
    { "componentSkuId": 2, "ratioQty": 3, "availableQty": 15, "maxBundles": 5 }
  ]
}
```
- 404：`MDM_BUNDLE_NOT_FOUND`
- 说明：`availableQty = min(floor(componentAvailable / ratioQty))`，套装本身无库存行。

## 5. 应收 / 收款

### 5.1 GET `/receivables`
- 权限：`sal:read`
- Query：`customerId`、`status`（OPEN/SETTLED/VOIDED）、`overdue`（true/false）、`page`、`size`
- 200：`ApiPageResponse<Receivable>`

### 5.2 GET `/receivables/{id}`
- 权限：`sal:read`
- 200：`ApiResponse<Receivable>`
- 404：`SAL_RECEIVABLE_NOT_FOUND`

### 5.3 GET `/receivables/summary`
- 权限：`sal:read`
- Query：`customerId`（必填）
- 200：
```json
{
  "customerId": 1,
  "shippedAmount": 100000,
  "returnedAmount": 5000,
  "receivedAmount": 40000,
  "balance": 55000,
  "overdueAmount": 0
}
```

### 5.4 POST `/customer-receipts`
- 权限：`sal:receipt`
- 请求头：`X-Request-Id`
- Body：
```json
{
  "customerId": 1,
  "amount": 40000,
  "bizDate": "2026-10-23",
  "remark": "银行转账",
  "allocations": [
    { "receivableId": 7, "amount": 30000 },
    { "receivableId": 8, "amount": 10000 }
  ]
}
```
- 201：`ApiResponse<CustomerReceipt>`
- 400：`SYS_VALIDATION_ERROR`（金额非正/分配为空/分配金额非正）
- 409：`SAL_RECEIPT_UNBALANCED`（`Σ allocations != amount`）
- 409：`SAL_RECEIPT_OVER_ALLOCATED`（任一应收余额不足）
- 409：`SAL_RECEIVABLE_NOT_FOUND`（应收不存在/不属于该客户/已作废）
- 409：`SYS_DUPLICATE_REQUEST`（幂等键复用）
- 说明：**部分收款** = amount < 应收余额；核销守恒要求分配合计精确等于收款金额。

### 5.5 GET `/customer-receipts`
- 权限：`sal:read`
- Query：`customerId`、`page`、`size`
- 200：`ApiPageResponse<CustomerReceipt>`

### 5.6 GET `/customer-receipts/{id}`
- 权限：`sal:read`
- 200：`ApiResponse<CustomerReceipt>`

## 8. 错误码清单（新增）

| 错误码 | HTTP | 场景 |
|---|---|---|
| `SAL_QUOTE_NOT_FOUND` | 404 | 报价单不存在 |
| `SAL_QUOTE_STATUS_ILLEGAL` | 409 | 非法状态转移/过期/重复转化 |
| `SAL_SHIPMENT_NOT_FOUND` | 404 | 发货单不存在 |
| `SAL_SHIPMENT_STATUS_ILLEGAL` | 409 | 非 DRAFT/PICKING/PICKED 的操作 |
| `SAL_SHIPMENT_OVER_PICK` | 409 | 扫码累计超计划数量 |
| `SAL_RECEIVABLE_NOT_FOUND` | 404 | 应收不存在 |
| `SAL_RECEIPT_UNBALANCED` | 409 | 核销明细合计 ≠ 收款金额 |
| `SAL_RECEIPT_OVER_ALLOCATED` | 409 | 核销超过应收余额 |
| `SAL_CREDIT_LIMIT_EXCEEDED` | 409 | 信用敞口超限 |
| `MDM_BUNDLE_NOT_FOUND` | 404 | 套装不存在 |
| `MDM_BUNDLE_DUPLICATED` | 409 | 套装编码/组件重复 |
| `MDM_BUNDLE_DISABLED` | 409 | 套装已停用 |

## 9. 新增表与闸门 3 说明

| 表 | 对应端点/页面 | 理由 |
|---|---|---|
| `sales_quotes` / `sales_quote_lines` | `/sales-quotes` + 报价页 | FR-SAL-05 需要独立保存报价，不能复用出货单（出货单建单即预占） |
| `customer_receipts` | `/customer-receipts` + 应收页 | FR-SAL-08 的"Σ核销 == 收款单金额"需要收款抬头 |
| `so_shipment_plans` | `POST /sales-orders/{id}/shipments` + 发货页 | 一次计划可拆多张按仓发货单；用独立计划头保证同键重放 |
| `customer_credit_snapshots` | 信用页 / 建单 | 蓝图 §4.1 明确要求；日期走 ClockProvider |

`so_shipments` / `shipment_lines` / `customer_receivables` / `receivable_allocations` /
`product_bundles` / `bundle_items` 均按任务书与蓝图落表，并有端点、页面与 `@CaseId` 用例。
