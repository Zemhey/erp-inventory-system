### 2.2 已有 `ReceiveRequest` / `PurchaseOrderLine` 的向后兼容变更

```yaml
    ReceiveRequest:
      type: object
      required: [lines]
      properties:
        lines:
          type: array
          minItems: 1
          items:
            type: object
            required: [lineId, qty]
            properties:
              lineId: { type: integer, format: int64 }
              qty: { type: integer, minimum: 1 }
              batchNo: { type: string, maxLength: 64 }
              productionDate: { type: string, format: date }
              expiryDate: { type: string, format: date }
              # V2-2 新增：本次到货中的合格数量，缺省 = qty
              qcQty:
                type: integer
                minimum: 0
                description: 本次合格数量；<= qty。只有合格量入库存/应付
              qcNote: { type: string, maxLength: 500 }

    PurchaseOrderLine:
      type: object
      required: [id, lineNo, skuId, qty, receivedQty, openQty, unitPriceAmount, amount]
      properties:
        id: { type: integer, format: int64 }
        lineNo: { type: integer, minimum: 1 }
        skuId: { type: integer, format: int64 }
        qty: { type: integer, minimum: 1 }
        receivedQty: { type: integer, minimum: 0, description: 累计到货量（含不合格） }
        # V2-2 新增
        qcQty: { type: integer, minimum: 0, description: 累计合格量 }
        qcStatus: { type: string, enum: [NONE, PASSED, PARTIAL, FAILED] }
        qcNote: { type: string, nullable: true }
        rejectedQty: { type: integer, minimum: 0, description: '= receivedQty − qcQty' }
        openQty: { type: integer, description: '= qty − receivedQty' }
        unitPriceAmount: { type: integer, format: int64, minimum: 0 }
        amount: { type: integer, format: int64, minimum: 0 }
```

```yaml
      required: [purchaseAmount, returnAmount, paidAmount, balance,
                 paymentTotal, allocationTotal, balanced, conserved]
      properties:
        supplierId: { type: integer, format: int64, nullable: true }
        purchaseAmount: { type: integer, format: int64 }
        returnAmount: { type: integer, format: int64 }
        paidAmount: { type: integer, format: int64 }
        balance: { type: integer, format: int64 }
        paymentTotal: { type: integer, format: int64, description: Σ付款单金额 }
        allocationTotal: { type: integer, format: int64, description: Σ核销明细 }
        balanced:
          type: boolean
          description: balance == purchaseAmount − returnAmount − paidAmount
        conserved:
          type: boolean
          description: paymentTotal == allocationTotal == paidAmount

    SupplierPaymentRequest:
      type: object
      required: [supplierId, amount, allocations]
      properties:
        supplierId: { type: integer, format: int64 }
        amount: { type: integer, format: int64, minimum: 1 }
        bizDate: { type: string, format: date }
        remark: { type: string, maxLength: 500 }
        allocations:
          type: array
          minItems: 1
          description: Σamount 必须等于付款金额；同一 payableId 只出现一次
          items:
            type: object
            required: [payableId, amount]
            properties:
              payableId: { type: integer, format: int64 }
              amount: { type: integer, format: int64, minimum: 1 }

    SupplierPaymentResult:
      type: object
      required: [paymentNo, paymentAmount, allocations]
      properties:
        paymentNo: { type: string, example: PY20261023-0001 }
        paymentAmount: { type: integer, format: int64 }
        allocations:
          type: array
          items:
            type: object
            required: [payableId, amount]
            properties:
              payableId: { type: integer, format: int64 }
              amount: { type: integer, format: int64 }
```

## 4. 错误码新增（`ErrorCode.java` → docs/05 §4）

| 错误码 | HTTP | 触发点 |
|---|---|---|
| `PUR_REQ_NOT_FOUND` | 404 | 请购单不存在 |
| `PUR_REQ_STATUS_ILLEGAL` | 409 | 请购单状态不允许提交/审核/转化；已转化后再改或再转 |
| `PUR_REQ_CONVERT_EXCEED` | 409 | 转单数量 > 申请数量 |
| `PUR_RECEIPT_NOT_FOUND` | 404 | 到货单不存在 |
| `PUR_QC_QTY_INVALID` | 400 | 合格数量 < 0 或 > 本次到货量 |
| `PUR_RETURN_NOT_FOUND` | 404 | 采购退货单或原到货行不存在 |
| `PUR_RETURN_STATUS_ILLEGAL` | 409 | 退货单状态不允许执行/作废 |
| `PUR_RETURN_QTY_EXCEED` | 409 | 退货数量超过合格量 − 已退量 |
| `PUR_RETURN_EXCEED_PAYABLE` | 409 | 退货金额超过该到货单应付余额（已付款部分不能被退货冲掉） |
| `PUR_PAYABLE_NOT_FOUND` | 404 | 应付单不存在 |
| `PUR_PAYMENT_AMOUNT_MISMATCH` | 400 | Σ核销明细 ≠ 付款金额，或金额非正、同一应付重复出现 |
| `PUR_PAYMENT_SUPPLIER_MISMATCH` | 400 | 核销的应付不属于该供应商 |
| `PUR_PAYMENT_EXCEED_PAYABLE` | 409 | 核销额超过应付余额（**业务冲突，不是 401**） |

权限失败仍由 IAM 处理：未登录 `401 IAM_UNAUTHENTICATED`，无权限 `403 IAM_FORBIDDEN`；
上述业务码不会返回 401。
