## 2. 口径（先写死，再写 SQL）

1. **单据口径**：进货/出货统计、经营报表里的进货/销售金额，按 `biz_date` 闭区间 + 状态 `PARTIAL/COMPLETED` + 已执行数量 > 0。
2. **流水口径**：经营报表的期初/入/出/期末、周转与呆滞，按 `inventory_ledger.occurred_at`；这是 INV-6 的事实源（领域文档 §4）。
3. **经营日报**：`dimension=day` 逐自然日覆盖 `[from,to]`，空日也出行；`dimension=month` 覆盖 from/to 所在的**完整自然月**（首月从月初、末月到月末），保证每月恒等式成立。
4. **周转天数**：`((期初 + 期末) / 2) × 区间天数 / 区间出库`，一位小数；出库为 0 时为空（页面 `-`）。
5. **呆滞**：以 `to` 为观察日，最近一次出库日（从未出库则取首次流水日）距今天数 `idleDays >= deadDays`。
6. **贡献/复购**：数量/金额/单据数与出货统计同一 SQL 公式（行折扣 + 同一状态集合）；复购 = 期间单据数 ≥ 2；新客 = `from` 之前无任何已执行出货单；复购率为万分比整数。
7. **账龄**：AR 以 `due_date` 起算、AP 无约定到期日故以 `biz_date` 起算；未到期/无到期日归 0–30；`asOf - 起算日` 落在 0–30 / 31–60 / 61–90 / >90；只统计未作废且余额 > 0；桶合计必须等于余额。
8. **导出**：与页面调用同一个 ApplicationService 方法，金额统一「分 → 元、两位小数」，周转天数一位小数，复购率两位小数百分比；CSV 用 UTF-8 BOM + CRLF。
