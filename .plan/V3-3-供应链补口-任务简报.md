## 3. 第二部分：库存智能（新增后端）

### FR-V3-18 库存预警

**表改造**（加列不加表）：`mdm_skus`（或 `products`，按实际表名）加三列：
```sql
ALTER TABLE mdm_skus ADD COLUMN safety_stock numeric(18,3) DEFAULT 0;
ALTER TABLE mdm_skus ADD COLUMN min_stock    numeric(18,3) DEFAULT 0;
ALTER TABLE mdm_skus ADD COLUMN max_stock    numeric(18,3) DEFAULT 0;
```
**端点**：
- `GET /api/v1/inventory/alerts?type=low|overstock|slow|expiring`
  - `low`：可用量 < safety_stock
  - `overstock`：可用量 > max_stock
  - `slow`：90 天无出库流水且有库存
  - `expiring`：批次效期 < 30 天
**页面** `src/views/inv/InventoryAlertView.vue`：4 个 Tab + 数量徽标 + 一键跳转补货建议。

**验收**：改一个 SKU 的安全库存到高于现有库存 → 预警列表出现它。

### FR-V3-19 补货建议

**端点**：`GET /api/v1/inventory/replenishment`，返回每个低库存 SKU 的建议采购量：
```
建议量 = max_stock - 可用量 - 在途量（已下未到）
若建议量 <= 0 则不返回
```
**幂等**：重复调用结果一致（纯查询，不写库）。
**页面** `src/views/inv/ReplenishmentView.vue`：建议列表 + 多选 + "一键生成请购单"（调现有请购接口）。

**验收**：同一 SKU 有在途采购单时，建议量扣掉在途；点一键生成能出请购单。

## 4. 第三部分：PRM 价格与促销（新模块）

新建包 `com.erp.prm/{api,application,repository,domain}`。

### FR-V3-20 价格方案

```sql
prm_price_plan(id, tenant_id, code, name, plan_type, /* CUSTOMER_LEVEL / CUSTOMER / AGREEMENT */
               priority int, start_date, end_date, enabled, remark, ...)
prm_price_plan_item(id, tenant_id, plan_id, sku_id, price numeric(18,2), discount_rate numeric(5,4), min_qty, ...)
```
**取价优先级**（必须写进代码注释，答辩会问）：
`客户协议价 > 客户等级价 > 商品标准售价`

**端点**：`/api/v1/prm/price-plans`（CRUD）、`GET /api/v1/prm/price?skuId=&customerId=&qty=`
**页面** `src/views/prm/PricePlanView.vue`：方案列表 + 明细行编辑 + 取价试算小工具。

**验收**：建一个客户等级价，用该等级客户查价返回等级价；再建协议价，返回协议价。

### FR-V3-21 促销活动

```sql
prm_promotion(id, tenant_id, code, name, promo_type, /* TIME_DISCOUNT / FULL_REDUCE / QTY_DISCOUNT */
              start_time, end_time, priority, status, remark, ...)
prm_promotion_rule(id, tenant_id, promotion_id, condition_json, benefit_json, ...)
```
**简化**：`condition_json` / `benefit_json` 存 JSON 字符串，不强求结构化（作业够用）。
**页面** `src/views/prm/PromotionView.vue`：活动列表 + 规则编辑（表单拼 JSON）+ 生效状态。
**验收**：建一个满减活动（满 1000 减 100），在出货单算价时生效。

> 如果时间紧，促销只做"展示 + 手工录入"，**不接到算价链路**，在报告里写明未接入。不要为了接进去改坏现有的折扣逻辑。

## 5. 第四部分：系统工具（技术最简单，最撑观感）

### FR-V3-27 消息通知

```sql
sys_notification(id, tenant_id, user_id, title, content, notify_type, /* TODO / WARN / INFO */
                 biz_type, biz_id, read_flag boolean, read_at, created_at, ...)
```
**触发点**（接 3~4 个就够，不要全接）：进货单待审 → 通知审批人；库存低于安全库存 → 通知仓管；应收逾期 → 通知财务。
**端点**：`GET /api/v1/notifications?unreadOnly=`、`POST .../{id}/read`、`POST .../read-all`、`GET .../unread-count`
**页面**：顶栏铃铛（未读数徽标 + 下拉最近 10 条）+ `src/views/sys/NotificationView.vue` 全量列表。
⚠️ 顶栏是 `MainLayout.vue`，**那是 W1 的文件，不要改**。铃铛放在你自己的组件里，让 W1 合并时接入，或者放在页内。
**验收**：造一条待审单据 → 铃铛出现未读；点已读后数字减少。

### FR-V3-26 打印模板

```sql
sys_print_template(id, tenant_id, code, name, doc_type, template_content text, page_size, is_default, ...)
```
**简化**：模板用**纯 HTML + 占位符**（`{{doc.no}}`、`{{item.name}}`），不做可视化设计器。
**端点**：`/api/v1/sys/print-templates`（CRUD）、`GET /api/v1/sys/print-templates/{code}/render?docId=`
**页面** `src/views/sys/PrintTemplateView.vue`：模板列表 + 编辑（textarea + 变量说明）+ 预览（iframe 渲染 HTML）。
**打印**：浏览器 `window.print()` + `@media print` 样式即可。
**验收**：建一个进货单模板，选一张单据能预览出带数据的 HTML 并打印。

### FR-V3-28 导入导出中心

**导出**：现有 `rpt/api/ReportExportController` 已有，复用它。
**导入**：做**通用 CSV 导入**（不要做 Excel 解析，POI 依赖重）：
- 端点 `POST /api/v1/sys/import/{entity}`（`entity` = product / customer / supplier）
- 流程：下载模板 CSV → 上传 → 校验（必填/编码唯一/外键存在）→ 返回"成功 N 条、失败 M 条 + 每行错误原因"
- **要求**：失败行**不入库**（要么全成功，要么报错让用户改），避免半截数据
**页面** `src/views/sys/ImportView.vue`：三步向导（选实体 → 上传 → 结果）。
**验收**：导入 5 行有 1 行编码重复 → 返回 4 成功 1 失败并指出第几行。

## 6. 技术约束

- **包结构**：新模块 `com.erp.prm/{api,application,repository,domain}`；其余功能放现有模块（`inv` / `sys` / `pur` / `sal`）。
  ⚠️ 项目有 `ArchitectureTest`，依赖方向遵守现有约定。
- **迁移**：`V21__v3_supply.sql`，**一个文件**，含 ALTER + 建表。已应用的迁移不改内容。
- **契约**：只追加自己 tag（`prm` / `inv` / `sys`）下的节点，**不重排、不改别人的**。
- **错误码**：追加到 `ErrorCode.java` 末尾（如 `PRM_PRICE_PLAN_CONFLICT(409)`、`SYS_IMPORT_VALIDATION_FAILED(400)`），最后一条带分号。
- **新表必须带 `tenant_id`**，并加入 `shared/tenant/TenantTables.java` 的 `ALL` 集合。
- **权限码**：`prm:read` / `prm:write` / `sys:print` / `sys:import`，写进角色初始化。
