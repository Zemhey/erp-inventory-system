## 三、D 盘清理：一条命令

已确认：**15 个待删目录的分支全部已并入 main，worktree 元数据也已清理**，现在它们只是普通文件夹。安全守卫拦了自动批量删除，请你在 **PowerShell（管理员）** 里跑这一条：

```powershell
$base = "D:\MajorCacheFolder\Company system"
@("erp-tnt-ui","erp-mdm-fields","erp-m4b","erp-m7-ai","erp-m4-miniapp",
  "erp-v22","erp-v23","erp-v26-aps","erp-v24","erp-v21",
  "erp-m25-reversal","erp-m6-deploy","erp-v25-audit","erp-contract") |
  ForEach-Object { Remove-Item -LiteralPath (Join-Path $base $_) -Recurse -Force -ErrorAction SilentlyContinue }

@("erp-temp","erp-tmp-b3-web-cache","tmp","tmp-v27") |
  ForEach-Object { Remove-Item -LiteralPath ("D:\" + $_) -Recurse -Force -ErrorAction SilentlyContinue }

# 删 junction（保留 erp-build 与 erp-build-v29-mobile）
Get-ChildItem "D:\" -Directory -Force | Where-Object {
  $_.Name -like "erp-build-*" -and $_.Name -ne "erp-build-v29-mobile"
} | ForEach-Object { [System.IO.Directory]::Delete($_.FullName, $false) }

Write-Output "清理完成"
```

**回收约 3.1 GB。** 注意两点：
1. junction 必须用 `Directory.Delete(path, false)` 或 `rmdir` —— **不能用 `Remove-Item -Recurse`**，那有删掉目标内容的风险。
2. **不要删** `erp-v29-mobile`（B3 小程序扫码未完成，有 707 个暂存文件）和 `erp-build-v29-mobile`。

如果要连第 ② 层（`erp-final` / `erp-v2d1` / `erp-e1-dict` / `erp-v28` / `erp-ui-ia` / `erp-v2c1` / `erp-v2c3` / `erp-v27` / `erp-v2c2`，约 1.2 GB）一起清，先告诉我，我把它们的 `git diff --cached` 导出成 patch 再删。
