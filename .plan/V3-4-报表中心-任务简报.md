## 0. 一句话目标（先看清楚，这条泳道最轻）

**报表的后端其实已经做完了，前端只有一个页面。** 实际存在的端点：

```
GET /api/v1/reports/inventory-summary     进销存汇总
GET /api/v1/reports/purchase              进货统计
GET /api/v1/reports/sales                 出货统计
GET /api/v1/reports/inventory-turnover    库存周转
GET /api/v1/reports/aging                 账龄（应收/应付）
GET /api/v1/reports/customer-contribution 客户贡献
GET /api/v1/reports/operating             经营报表
```
另有 `rpt/api/ReportExportController` 负责 CSV 导出，`cst/api/MarginController` 负责毛利分析。

**你要做的是**：一套统一的报表中心框架（左侧报表目录 + 参数区 + 结果区 + 导出/打印），把上面 7 个接口各做成一个页面，再补 3 张缺的（呆滞分析、销售明细、采购明细），最后做一个数据大屏。

**这批不需要造复杂后端**，70% 是前端工作。做完之后，系统会"有很多张报表" —— 这是"大型系统"最便宜的证据。

## 2. 任务清单

### FR-V3-31 报表中心框架（先做，后面 10 张表都复用它）

新建 `src/views/rpt/ReportCenterView.vue`，三栏布局：

```
┌─────────────┬──────────────────────────────────────┐
│ 报表目录     │  参数区（期间/仓库/客户/商品 + 查询）    │
│ ├ 经营分析   ├──────────────────────────────────────┤
│ ├ 库存报表   │  工具栏（导出 CSV / 打印 / 刷新）        │
│ ├ 采购报表   ├──────────────────────────────────────┤
│ ├ 销售报表   │  结果区（表格 + 合计行）                │
│ └ 财务账龄   │                                      │
└─────────────┴──────────────────────────────────────┘
```

**实现要点**：
- 抽 `src/components/report/ReportShell.vue`，props：`{ title, paramsSchema, loader, columns }`
- `paramsSchema` 用配置描述参数（类型 date/dateRange/select/text），自动渲染表单
- `loader` 是返回 `Promise<rows[]>` 的函数，每个报表页只提供 loader + columns
- 结果区统一支持：列宽、数字千分位、合计行、CSV 导出（复用现有导出端点或前端生成）
- **打印**：`@media print` 样式，打印时隐藏目录和工具栏

**验收**：框架能渲染一张空报表；点"导出"能下 CSV。

### FR-V3-33 数据大屏

新建 `src/views/rpt/DataScreenView.vue`，**独立全屏页**（不走 MainLayout，路由加 `meta.fullscreen = true`）：

- 深色背景（`#0b1220` 系），主色青蓝，**不要用浅色主题的变量**
- 顶部：标题 + 当前时间 + 滚动公告
- 中间 6 个区块：
  1. 今日 KPI 四联（销售额/订单数/出库量/库存总值）—— 数字滚动动画
  2. 近 30 天销售趋势（折线）
  3. 库存按仓库分布（环形图）
  4. 热销 TOP10（横向条形）
  5. 应收账龄（柱状）
  6. 地图/排行榜（没有地图就用"客户销售 TOP"列表）
- 自适应：`transform: scale()` 按 1920×1080 设计稿缩放
- **数据源**：复用 `/reports/*` 与 `/dashboard/summary`（W1 在做）；W1 没做完就用 `/reports/sales` + `/inventory-summary`

**验收**：全屏打开无滚动条，缩放窗口不变形，图表有数据。

### FR-V3-34 报表导出与打印（贯穿）

- CSV 导出：优先复用 `ReportExportController`；没有覆盖的报表用前端 `Blob` 生成
- 打印：统一 `@media print`，A4 横向，表格不截断
- **验收**：任一张报表导出 CSV 能用 Excel 打开且中文不乱码（**必须 UTF-8 BOM**）

## 3. 技术约束

- **图表库**：引入 `echarts` + `vue-echarts`，**按需引入**（`use([...])` 只注册用到的图表类型），不要全量 import，否则 build 体积爆炸。
- **包结构**：如新增后端，放 `com.erp.rpt/{api,application,repository}`，**不新建模块**。
- **迁移**：`V22__v3_report.sql`（如需加索引或报表中间表；**没有就不建文件**）。
- **契约**：新增端点写进 `openapi.yaml`，只追加 `rpt` tag 下的节点。
- **错误码**：如需新增，追加到 `ErrorCode.java` 末尾，最后一条带分号。
- **前端路由**：只新建 `src/router/modules/rpt.ts`，导出路由数组，**不要改 `router/index.ts`**（W1 负责）。
